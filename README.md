# vadzim.dev · strona wizytówka

My personal business card website. Built from scratch with plain **HTML, CSS and JavaScript**, no frameworks.

**Live:** https://vadzim-dev.github.io

## Features

- Dark and light theme (remembers your choice, follows system setting)
- Interactive terminal: type `help` to see the commands (history with ↑ / ↓, autocomplete with Tab)
- Typing animation in the hero section
- 3D tilt cards with a light that follows the cursor
- Scroll reveal animations and reading progress bar
- Fully responsive, respects `prefers-reduced-motion`
